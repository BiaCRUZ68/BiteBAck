# Biteback Historical Evidence Ledger
Use one ledger per episode. The script's factual claims must map to a ledger entry where verification matters.

| ID | Exact claim (not interpretation) | Source/title | Author or institution | Date | URL / page / folio / passage | Evidence type | Confidence/status | Qualification in narration | Visual implications and anachronism risks |
|---|---|---|---|---|---|---|---|---|---|
| C-001 |  |  |  |  |  | Primary / archaeological-material / scholarly synthesis / secondary reporting | Well-supported / contested / plausible inference / unknown |  |  |

## Rules
- Keep a factual claim separate from commentary or interpretation.
- Prefer primary sources, credible archaeological or material evidence, and recognized scholarly research.
- Verify the source's date, authorship, context, translation, and intended purpose before using it.
- Do not invent page/folio numbers, citations, quotes, dates, quantities, or URLs.
- Record contradictory evidence and explain how it affects the script.
- Distinguish evidence that a food existed from evidence about exact ingredients, preparation, frequency, availability, social class, or universal use.
- Mark reconstructions as reconstructions. Visual plausibility is not proof.
- For food history, record time, place, community, status/rank, season, supply context, and occasion when known.
- Mark a claim “unknown” when reliable evidence is insufficient; do not fill gaps with confident-sounding speculation.
- Include a note for every key shot that could accidentally overstate the evidence.
