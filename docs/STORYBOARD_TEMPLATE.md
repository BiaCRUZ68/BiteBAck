## Prompt delivery rule
For each shot, response layout must always be:
1. Shot title.
2. Exact narration segment (verbatim).
3. IMAGE PROMPT in a dedicated code block.
4. VIDEO PROMPT in a separate dedicated code block.

Never combine the image and video prompts into one block. Never replace a prompt with “same as above” or an abbreviated placeholder.
