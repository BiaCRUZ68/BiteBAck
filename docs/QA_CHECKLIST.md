# Biteback Production QA Checklist
Use before approving the script, before scaling image/video generation, and before calling a finished episode ready.

## A. Topic and research gate
- [ ] The episode has one clear central question.
- [ ] Food is integral to the explanation, not just a hook.
- [ ] Key facts have credible sources in the evidence ledger.
- [ ] Primary-source context and dates are understood.
- [ ] Disputes and uncertainty are clearly marked.
- [ ] No unsupported recipe, quote, date, measurement, or historical detail has been invented.
- [ ] Modern culinary assumptions have not been projected backward without evidence.

## B. Full-script approval gate
- [ ] The complete narration was written before shot-level prompts.
- [ ] Hook creates curiosity without making a false promise.
- [ ] Each block introduces useful information or advances the explanation.
- [ ] Chronology, causal logic, transitions, and conclusion are coherent.
- [ ] Redundant facts, repeated concepts, filler, and unnecessary questions have been removed.
- [ ] The script answers its opening question.
- [ ] All significant claims are checked against the evidence ledger.
- [ ] The channel owner approved the complete script before image/video prompt production.

## C. Storyboard coverage gate
- [ ] Each shot quotes its exact approved narration segment verbatim.
- [ ] Every narration segment is visually covered, with no unexplained gaps.
- [ ] Shot order follows narration order and uses stable shot IDs.
- [ ] Every shot has a clear narrative purpose.
- [ ] Adjacent compositions/action beats are not repetitive without reason.

## D. Image prompt gate
- [ ] Every shot has an image prompt in its own dedicated code block.
- [ ] Prompt is self-contained and copy-ready.
- [ ] 16:9 aspect ratio is explicit unless otherwise requested.
- [ ] Main subject and action are large, clear, and readable.
- [ ] Wide scenes have meaningful activity filling the frame; subjects are not tiny.
- [ ] Setting, clothing, food, tools, materials, architecture, and environment fit time/place.
- [ ] No unsupported ingredient, object, costume, or cultural assumption is presented as fact.
- [ ] Visual style follows Biteback's hand-drawn ink, watercolor and collage-textured identity.
- [ ] For Alex/Lia, label actor, include complete character description, and explicitly require the attached official character sheet.

## E. Video prompt gate
- [ ] Every shot has a video prompt in its own separate code block.
- [ ] Video prompt is self-contained and copy-ready.
- [ ] The shot duration is stated.
- [ ] It contains a timed action plan.
- [ ] The subject physically acts; object movement has cause and effect.
- [ ] Camera movement supports the action and does not substitute for it.
- [ ] The shot has a clear starting and ending state.
- [ ] Movement is plausible and does not loop generically.
- [ ] Sound is ASMR/natural ambience only and synchronized to visible action.
- [ ] Explicitly excludes narrator, voice-over, dialogue, speech, lip-sync, and music.
- [ ] Alex/Lia stay silent and use the mandatory character reference protocol.

## F. Character continuity
- [ ] Alex matches his master sheet: spiky dark-brown hair, head/face/eyes/nose, proportions, outfit silhouette, linework and colors.
- [ ] Lia matches her master sheet: auburn-red high bun and loose curls, face, head proportions, linework, colors and outfit silhouette.
- [ ] Full descriptions are repeated in both prompts wherever a character appears.
- [ ] Character expressions and gestures vary without redesigning identity.
- [ ] Characters are not forced into historical scenes as supposed witnesses.
- [ ] Costume alterations are justified by the scene and preserve core identity.

## G. Sound and edit
- [ ] All generated video prompts specify ASMR and natural ambience only.
- [ ] No generated clip contains a request for narrator/voice-over/dialogue/music.
- [ ] Historical sound choices are consistent with visible objects and actions.
- [ ] Narration is added separately in editing.
- [ ] Final visuals are aligned to the real narration recording and pauses.
- [ ] Transitions and shot lengths feel intentional; no padding.

## H. Final delivery
- [ ] Script version, evidence ledger, and storyboard agree.
- [ ] No key factual claim is stronger in the image than in the script.
- [ ] Every prompt is reviewed for anachronisms, omissions, repetition, and clarity.
- [ ] Packaging and thumbnail are compelling but not misleading.
- [ ] Final cut has intelligible narration, balanced sound, appropriate pacing and checked captions.
- [ ] Only after all critical items pass is the package marked approved.
