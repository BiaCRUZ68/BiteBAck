# Biteback Character Prompt Lock
**Version:** 1.1.0  
**Effective date:** 2026-10-23  
**Status:** Mandatory permanent production rule for every Biteback episode until explicitly updated by the channel owner.

This document strengthens the character-reference protocol in `BITEBACK_WORKFLOW.md` and `CHARACTER_BIBLE.md`. If a shorter template, older prompt, or episode note conflicts with this document, follow this document.

## Non-negotiable prompt rule

Whenever Alex and/or Lia appears in a shot, the **complete applicable character description and identity-lock rules must be written inside that individual image prompt AND inside that individual video prompt**. Do not rely on a separate master prompt, a previous shot, memory, shorthand such as “same character,” or an instruction to prepend a reusable block. Every prompt must be independently copy-ready.

- If only Alex appears, include Alex's complete description and continuity rules in both prompts.
- If only Lia appears, include Lia's complete description and continuity rules in both prompts.
- If both appear, include the complete Alex block and the complete Lia block separately in both prompts.
- If neither appears, do not force either character into the shot and do not add character boilerplate.
- Explicitly identify **Actor 1: Alex** and/or **Actor 2: Lia**.
- In every applicable prompt, require the attached official character sheet as the mandatory primary visual reference. If the reference is not actually attached or available in the current working context, state that it is needed; never claim it was used.
- Repetition is intentional: image and video generators may not retain context from other prompts.
- A video prompt must repeat the identity lock even when it uses a generated still as its starting frame. The starting frame does not replace the written character description.
- The default character outfit remains unchanged. Adjust clothing only when a specific historical-period requirement makes it necessary; preserve the face, hair, head shape, proportions, linework, and recognizable identity.
- Alex and Lia are silent visual investigators. Do not request speech, dialogue, narration, lip-sync, or a mouth movement that implies speech.
- Keep them out of historical reconstructions as supposed eyewitnesses or documented participants. Use them only in a clearly editorial/investigative framing when appropriate.

## Actor 1: Alex — mandatory full prompt description

Use the following complete specification inside every image prompt and every video prompt where Alex appears:

“**Actor 1: Alex.** Use the attached image **‘Alex — Biteback Character Master Sheet’** as the mandatory primary visual reference. Reproduce the same character, not a redesign. Alex is a cheerful, curious male stickman explorer, with a personality and voice age of about 40. He has tousled, spiky dark-brown hair; a large expressive cartoon head; warm light-peach skin; big white eyes with dark pupils; thick expressive eyebrows; a prominent rounded nose; and a wide friendly smile. His limbs are simple, thin black stickman limbs with consistent proportions. His standard outfit is a rustic ochre-brown tunic with a belt and small leather pouches. His signature prop is a wooden cooking spoon when contextually appropriate. Visual style: hand-drawn cartoon head, bold irregular black ink outlines, textured watercolor coloring, collage-textured aged parchment, and an earthy palette of ochre, terracotta, olive, and warm ivory. Personality: enthusiastic, curious, approachable, intelligent, occasionally clumsy, good-humored, and lively but natural. Match the official reference exactly: face, hairstyle, head shape, nose, eyes, head-to-body ratio, limb proportions, linework, colors, outfit silhouette, and core design. Do not alter his hairstyle or facial features or redesign him as a generic stickman. Change only expression, gaze, pose, and action as needed. Change clothing only if a specific historical-period requirement demands it, while preserving his core identity. Never render him as a realistic human, glossy 3D character, anime character, or in a different cartoon style. Alex is a silent visual investigator: no speaking, dialogue, narration, lip-sync, or narrated performance.”

Personality: observant, practical, intelligent, calm, resourceful, and curious. She investigates ingredients, checks evidence, connects food and history, and balances Alex’s enthusiasm with thoughtful context. Match the official reference exactly: face, hair color, high-bun shape, loose curls, head shape and proportions, eyes, nose, body proportions, linework, colors, outfit silhouette, and core design. Do not change her hairstyle or facial features or redesign her as a generic stickman. Change only expression, gaze, pose, and action as needed. Change clothing only if a specific historical-period requirement demands it, while preserving her core identity. Never render her as a realistic human, glossy 3D character, anime character, or in a different illustration style. Lia is a silent visual investigator: no speaking, dialogue, narration, lip-sync, or narrated performance.”

## Requirements for each shot delivery

For each storyboard beat, deliver:
1. The exact narration segment, verbatim.
2. A complete standalone **IMAGE PROMPT** in its own code block.
3. A complete standalone **VIDEO PROMPT** in a separate code block.
4. Repeat the full applicable character specification in both code blocks, not only once above the shot or in a shared preamble.
5. For video: retain the Biteback ASMR-only policy and specify timed visible physical actions, cause and effect, camera framing, and natural/ASMR sounds synchronized to visible action. Explicitly state: “No narrator, no voice-over, no dialogue, no speech, no lip-sync, no music.”

Do not replace the full prompt with a summary, placeholder, or reference to another prompt. Before delivery, QA every image/video prompt for a complete identity lock whenever the named character appears.
